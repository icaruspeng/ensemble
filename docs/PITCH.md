**"Google Docs had its multiplayer moment. Figma had its multiplayer moment. This is AI's."**

**2:20 — close.** "Runloop devboxes under every room. Reflex's crew grammar as the protocol — we built the multiplayer layer their schema promises. Codex on both sides of the glass: it built Ensemble, and it works inside it. A thousand private threads just became one shared, living thing. We're Ensemble."

## Q&A crib
- **Real?** All live: real devboxes, real codex exec, real tunnels. Happy to open the raw event stream.
- **Why you / why now?** YC's Fall-2026 RFS "Multiplayer AI" verbatim; agents now run hours-long work that whole teams share.
- **Codex usage?** Built BY three parallel headless Codex builders ×2 waves (session IDs in the repo) + Codex IS the product's workforce. 66 sessions today.
- **Sponsor tech?** Runloop: devbox-per-task, 25s provisioning, tunnels, snapshots. Reflex: their unshipped crew.* events implemented + Claude agents run through their control plane with our registered credentials.
- **Business?** Rooms are cheap (suspend economics); sell seats + metered agent spend; the ledger is the billing primitive.
- **What's missing?** Persistence, org auth, PR export — deliberate 9-hour cuts; the architecture takes them cleanly.

## Failure playbook (unchanged)
Wifi dies → two windows on the laptop. Agent flails → Interrupt IS the feature. Anything worse → snapshots rebuild the stage in ~2 min; rehearsal recording as last resort.
